# Automation-Systems

A collection of Google Apps Script automation systems I built and maintain.
All systems run fully automated (time-driven triggers, no human action
required) on top of Google Sheets, Gmail and Slack.

## Projects

| Project | Description |
| --- | --- |
| [smart-sheet-sync-automation](./smart-sheet-sync-automation) | Transfers records between Google Sheets based on status changes, applies business rules, and performs safe cleanup operations with timeout protection and comprehensive logging. |
| [Reach-out-system](./Reach-out-system) | Fully automated outbound email pipeline (initial request → follow-ups → reminder) with aggregated per-recipient emails, biweekly scheduling logic, send logs and Slack notifications. Sanitized version — all IDs, emails and names are placeholders. |
